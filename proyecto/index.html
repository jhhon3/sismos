PROYECTO DE PREVENCIÓN SÍSMICA

Reduciendo la latencia en alertas sísmicas mediante IoT local

Las alertas sísmicas convencionales sufren de retrasos críticos en la red. Nuestro proyecto utiliza un sensor de alta precisión en una protoboard conectado a una red local para procesar las vibraciones iniciales y enviar un aviso de emergencia directamente al teléfono móvil antes de que lleguen las ondas destructivas.

developer_board Circuito en Protoboard

Hardware Node

El circuito físico está ensamblado en una protoboard para validación de concepto. Consta de los siguientes componentes:

  • Microcontrolador (ESP32 / Wi-Fi)

    Procesa la señal localmente y gestiona el envío de la notificación por red.

  • Sensor MPU6050 / Acelerómetro

    Mide la aceleración sísmica y filtra falsos movimientos.

  • Zumbador / Buzzer (Opcional)

    Proporciona una alarma sonora inmediata en el lugar del sensor.

  • Lógica de Calibración

    Algoritmo en código para activar la alerta al superar un umbral crítico.

API / Webhook

Al detectarse la vibración en la protoboard, el microcontrolador hace una petición HTTP directa enviando un mensaje de alerta.

1. Nuestra idea 💡

  • ¿Qué queremos construir?

    Un sistema IoT autónomo de alerta sísmica rápida montado en protoboard que notifique al teléfono en tiempo real.

  • ¿Por qué escogimos esta idea?

    Porque vivimos en zonas de riesgo sísmico donde cada segundo de aviso previo puede salvar vidas.

  • ¿Qué problema queremos solucionar?

    La alta latencia y fallas de las notificaciones públicas cuando las redes de telefonía se colapsan.

search

2. ¿Qué investigamos?

¿Qué necesitamos aprender?

Programación de microcontroladores (Arduino/ESP32), lecturas de giroscopio I2C y comunicación serie/webhooks.

¿Qué información encontramos?

Las ondas P (primarias) se desplazan más rápido que las destructivas S, permitiendo detectar el sismo fracciones de segundo antes.

Fuentes consultadas

  • Documentación Oficial Arduino
  • Datasheet MPU6050
  • Estudios de Sismología Local

3. Nuestro diseño

Boceto Inicial

Diagrama de conexiones de protoboard vinculando pines VCC, GND, SDA y SCL entre el sensor y el procesador.

¿Cómo imaginamos el dispositivo?

Un nodo compacto con carcasa protectora, luz LED de estado e integración Wi-Fi de bajo consumo.

¿Qué queremos que haga?

Detectar vibraciones bruscas, filtrar falsos positivos y enviar alertas sonoras y digitales al instante.

inventory_2

4. Materiales

  • Protoboard + Jumpers

    Para interconectar todos los componentes sin necesidad de soldar.

  • Arduino UNO / ESP32

    Procesa las variables del sensor y se conecta a la red Wi-Fi.

  • Sensor Piezoeléctrico / MPU6050

    Mide la aceleración y vibración sísmica en Tinkercad.

  • Buzzer y LEDs

    Dan avisos audibles y visuales locales al activarse.

6. Pruebas y cambios

¿Qué probamos y qué funcionó?

Se simularon lecturas analógicas en Tinkercad. El sistema activó los actuadores al sobrepasar el valor definido en el monitor serie.

¿Qué problemas encontramos y qué cambiamos?

Problema: Sensibilidad inconsistente. Cambio: Se ajustó el tiempo de refresco (`delay`) en el código de Arduino para lecturas más estables.
